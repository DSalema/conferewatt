# Site do ConfereWatt

Páginas públicas do ConfereWatt (início, política de privacidade e termos de
uso), publicadas pelo GitHub Pages. Exigidas pelo Google para o app de
cópias no Google Drive.

Este repositório é **público**: aqui só entram estas páginas. O código do
programa e as faturas ficam no repositório privado.

- `index.html`: página inicial (tem os links para privacidade e termos)
- `privacidade.html`: Política de Privacidade
- `termos.html`: Termos de Uso
- `estilo.css`: aparência (paleta "Petróleo e papel", claro e escuro)
- `img/`: ícone e favicon

Para mudar um texto, edite o arquivo no próprio GitHub (ícone de lápis) e
salve ("Commit changes"). O site se atualiza em cerca de um minuto. Ao mudar a
política ou os termos, atualize também a data de vigência no topo da página.
